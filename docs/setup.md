# Montar el entorno de desarrollo

Guía para preparar un equipo Windows 11 desde cero. Hay dos partes: los pasos manuales en Windows, que el script no puede hacer, y los pasos dentro de Ubuntu, que automatiza `install.sh`.

## Resumen del orden

1. Windows: WSL2 y Ubuntu.
2. Windows: Rancher Desktop, Nerd Font, Alacritty, VS Code, IntelliJ IDEA.
3. Ubuntu: primer arranque y clonado del repositorio.
4. Ubuntu: ejecutar `install.sh`.
5. Ubuntu: pasos manuales después del script.
6. Comprobaciones finales.
